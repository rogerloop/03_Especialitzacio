7.- Gráfico de CSAT
 
  Probamos con frecuencias:
 
ggplot(Df, aes(x = factor(csat))) +
 geom_bar(fill = "steelblue") +
 labs(
   title = "Distribución de CSAT",
   x = "Nivel de satisfacción",
   y = "Frecuencia"
 )
 
 7.1.- ¿Qué hemos hecho?
 
 .- gglpot: creamos una gráfico del dataset Df
 .- geom_bar: le decimos que sea un gráfico de barras
 .- aes: definimos la variable. en el eje X= tipo de NPS
 .- Fill: coleramos el gráfico según la categoria
 .- labs: Colocamos los títulos del eje de las X Nivel de satisfacción) y el eje de las Y (Frecuencia )
 
Y lo pasamos a porcentajes


ggplot(Df, aes(x = factor(csat))) +
  geom_bar(aes(y = after_stat(count / sum(count) * 100)),
           fill = "steelblue") +
  labs(
    title = "Distribución de CSAT",
    x = "Nivel de satisfacción",
    y = "Porcentaje"
  )
