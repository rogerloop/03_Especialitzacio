## 📌 Descripción

Esta tarea corresponde a la actividad final del **Sprint 4 — Modelat SQL** del curso de especialización en **Data Analytics**.

El objetivo principal es diseñar, implementar y consultar una base de datos relacional a partir de diferentes archivos CSV, aplicando conceptos de:

- Modelado dimensional.
- Esquema estrella (*Star Schema*).
- Tablas de hechos y dimensiones.
- Importación de datos desde archivos CSV.
- Exploratory Data Analysis (EDA).
- Limpieza y transformación de datos.
- Definición de Primary Keys y Foreign Keys.
- Relaciones entre tablas.
- Subconsultas y `JOIN`.
- Funciones de agregación.
- CTEs (`WITH`).
- Window Functions.
- Relaciones muchos-a-muchos (N:M).
- `JSON_TABLE`.
- Transformación y normalización de datos.
